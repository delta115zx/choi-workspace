1. 설치
	node.js본체 설치

	패키지 설치
		npm install 이름 옵션
			-g : Node.js본체에 add-on
			   : 프로젝트에 add-on	

	nodemon(소스 수정시 자동재시작 add-on)
		npm install nodemon -g

	express(웹 백엔드 프로젝트 자동생성 add-on)
		npm install express -g
		npm install express-generator@4 -g

2. 프로젝트 생성
	프로젝트 만들곳에 가서 cmd
	2-1)  프로젝트 만들기
		express 프로젝트명
			express Dec08_1_NodeJSTest
	2-2) 기본 라이브러리 설치
		cd 프로젝트명
			cd Dec08_1_NodeJSTest
		npm install
	2-3) app.js파일 편집

3. 실행
	nodemon app.js
