6. Apache Tomcat(HTML/CSS, jQuery)톰켓
6-1. Java 설치
Java가 apt시스템에 없어서 sudo apt install java 이런식으로 설치가 안됨
sudo add-apt-repository ppa:openjdk-r/ppa -> Java가 있는 사설저장소 등록
sudo apt update : 목록 업데이트
sudo apt install openjdk-17-jdk : Java설치
java -version : 확인
 
6-2. Apache Tomcat WAS 다운받고, 압축풀기
cd ~
wget
https://dlcdn.apache.org/tomcat/tomcat-9/v9.0.113/bin/apache-tomcat-9.0.113.tar.gz
tar xvzf apache-tomcat-9.0.113.tar.gz
rm -rf apache-tomcat-9.0.113.tar.gz
cd apache-tomcat-9.0.113
 
6-3.  설정, 실행
vi conf/server.xml  : 서버 설정 파일
/20000 정도로 검색해서 port번호 수정
bin/startup.sh : ON
bin/shutdown.sh : OFF
 
6-4. 접속

8. FastAPI
수업때 하는 우분투 버전이 18.04라 FastApi+uvicorn 조합이 안됨
8-1.  Python 3.9버전을 설치할 수 있게 환경설정
sudo apt install build-essential zlib1g-dev libncurses5-dev libgdbm-dev libnss3-dev libssl-dev libreadline-dev libffi-dev curl software-properties-common
 
sudo apt update
 
8-2. 설치파일 다운로드
cd ~
wget https://www.python.org/ftp/python/3.9.13/Python-3.9.13.tar.xz
tar xvf Python-3.9.13.tar.xz
rm -rf Python-3.9.13.tar.xz
cd Python-3.9.13
 
8-3. 설치
./configure --enable-optimizations
make -j 12
sudo make altinstall
 
8-4. Python3.9 설치확인
python3.9 빠져나오고
pip3.9 list
 
8-5. FastAPI + Uvicorn 라이브러리 설치
pip3.9 install fastapi
pip3.9 install uvicorn[standard]
 
8-6. 실행
cd ~
cd Jan13
vi faTest.py
python3.9 -m uvicorn faTest:app --reload --host=0.0.0.0 --port=9999
 
 
8-8. 백그라운드 실행(PuTTY꺼도 실행되게)
cd Jan13
nohup python3.9 -m uvicorn faTest:app --reload --host=0.0.0.0 --port=9999 &
 
 
8-8. 백그라운드 실행중인거 종료
ps -ef : 실행중인 프로세스들
ps -ef|grep python3.9 : 실행중인 프로세스들 중에 python3.9 찾기 -> 프로세스 번호 확인
kill -9 번호
